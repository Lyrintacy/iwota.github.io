Fonts for text items.

Put a font file here. These formats work: .woff2, .woff, .ttf (TrueType) and
.otf (OpenType). Then in the workshop, on the General tab, add a font and type its
file name in "or file in public/fonts" (for example Display.ttf). The font is loaded
from this folder. Keep file names free of special characters where you can.
